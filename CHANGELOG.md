# Changelog

## v0.1.0 — 2026-10-16

First public source release of **KRunner macOS Spotlight Theme**.

- Native KRunner providers inside a continuous-corner translucent interface.
- Unified animated search/results surface with consistent glass tint.
- Soft hover and keyboard selection, measured row insets and bottom clearance.
- Right-aligned descriptions and native-action Tab badges with fixed padding.
- Removed model rows hidden immediately, preventing stale text overlap.
- Contextual app icon, passive Open hint and subtle illuminated upper rim.
- User-local installation, update, one-level rollback and uninstall.
- Normal build excludes developer screenshot and synthetic-input diagnostics.
- Native build and live visual/lifecycle validation on Fedora Asahi ARM64,
  Plasma 6.7.5 / Wayland; 16 automated tests passed.

See docs/VALIDATION.md for exact support and remaining untested configurations.
