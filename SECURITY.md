# Security reporting

Do not publish sensitive vulnerabilities, private query histories or screenshots
in a public issue. Until a private security contact is configured for the
repository, use GitHub's **private vulnerability reporting** feature if enabled,
or contact the maintainer privately through their established GitHub account.
Do not send tokens, credentials, whole home-directory backups or search history.

The project is a custom per-user KRunner executable that can invoke installed
KRunner providers and their actions. Review source and actions before use.
Installation and update modify a user systemd drop-in, but intentionally leave
system files and all global keyboard mappings untouched.
